# Product Requirements Document — Pathwise CC
### Version 2.0 | Replit-Optimized Build

---

## 1. Product Overview

### One-Sentence Description

**Pathwise CC is an AI-powered academic, transfer, scholarship, and career pathway advisor that helps community college students plan from enrollment to university transfer and early career preparation.**

### Problem Statement

Community college students often struggle to identify the right courses, realistic university targets, scholarship opportunities, and how academic choices connect to long-term careers. Official counseling resources are limited, fragmented, and hard to personalize. Pathwise CC provides structured, personalized roadmaps while reminding students to verify decisions with official counselors and university websites.

### Target Users

| User Type | Description |
|---|---|
| Transfer students | Students planning to transfer to a 4-year university |
| First-generation students | Students unfamiliar with transfer systems and application planning |
| Low-income students | Students needing scholarship, aid, and affordable pathways |
| Career-focused students | Students who want internships, research, and early career momentum |
| Exploratory students | Students unsure of major, university, or career direction |

### MVP Scope

1. Student profile intake
2. Academic and coursework input
3. Goal and preference intake
4. Curated university dataset (25–40 schools)
5. Curated scholarship and opportunity dataset
6. Pathway compatibility scoring
7. AI-generated pathway reports (three tiers)
8. Three-way pathway comparison view
9. Final guidebook generation (Markdown)
10. Saved profiles and pathway history

### Non-MVP Features — Deferred

| Deferred Feature | Reason |
|---|---|
| Live university database scraping | Legal risk, reliability concerns |
| Real-time degree audit | Requires official articulation data partnerships |
| ASSIST.org-style course validation | Deferred until structured imports exist |
| Full financial aid award prediction | Requires FAFSA/CADAA and institutional data |
| Automated scholarship application counts | Often unavailable or unreliable |
| AI acting as official counselor | Legal and ethical risk |
| Automated portal login to colleges | Security and compliance concerns |
| Full career outcome prediction | Requires labor market and alumni data integrations |
| PDF export | Phase 2 — use Markdown export in MVP |
| Google OAuth login | Phase 2 |

## 3. Updated Tech Stack for Replit

This stack is chosen specifically for Replit's environment, developer ergonomics, and zero-friction deployment.

| Layer | Technology | Reason |
|---|---|---|
| **Monorepo structure** | Single Replit project | Simpler than separate frontend/backend repos |
| **Frontend** | React 18 + Vite | Fast HMR, standard, Replit-compatible |
| **Styling** | Tailwind CSS v3 | Utility-first, no build config needed |
| **Component library** | shadcn/ui (Radix primitives) | Accessible, copy-paste components, no extra deps |
| **Backend** | Node.js + Express 5 | Lightweight, easy to extend |
| **Database** | PostgreSQL via Neon (Replit-native) | Persistent, free tier, serverless-friendly |
| **ORM** | Drizzle ORM | Lightweight, TypeScript-native, great with Neon |
| **Auth** | Replit Auth (OpenID Connect) | Zero-config for Replit environment |
| **AI** | Anthropic Claude API (`claude-sonnet-4-20250514`) | Best-in-class reasoning, structured output |
| **Session store** | connect-pg-simple (PostgreSQL sessions) | Persistent sessions, pairs with Neon |
| **File export** | Markdown download (client-side blob) | No extra dependencies for MVP |
| **Environment** | Replit Secrets | Never hardcode keys |
| **Deployment** | Replit Autoscale Deployments | One-click, handles scaling |

### Why Claude over OpenAI for this Product

- Claude's long context window handles large student profiles + full university datasets in a single prompt
- Better instruction-following for structured JSON output
- Safer for student-facing advice (lower hallucination rate on structured tasks)
- Anthropic's model is updated to `claude-sonnet-4-20250514` — use this exact string

## 6. Authentication — Replit Auth

Use Replit's built-in OpenID Connect. No password hashing, no JWT setup, no third-party auth service.

```js
// server/replitAuth.js — standard Replit OIDC pattern
import { setupAuth, requireAuth } from "./replitAuth.js";

// In server/index.js
setupAuth(app);

// On protected routes
app.get("/api/profiles", requireAuth, profilesRouter);
```

All protected API routes must use the `requireAuth` middleware. The frontend reads `/api/auth/user` to determine login state.

## 8. Compatibility Scoring Service

```js
// server/services/scoringService.js

export function calculateCompatibility(student, university, requirements) {
  const scores = {
    majorAlignment:   scoreMajorAlignment(student.intendedMajor, university.majors),
    gpaFit:           scoreGpaFit(student.currentGpa, requirements.recommendedGpa, requirements.minGpaEstimate),
    coursework:       scoreCoursework(student.completedCourses, requirements.requiredCourses),
    costFit:          scoreCostFit(student.financialSituation, university.costCategory),
    locationFit:      scoreLocationFit(student.geographicPreference, university.location),
    careerFit:        scoreCareerFit(student.careerGoal, university.careerTags),
    experienceAccess: university.experienceAccessScore ?? 70,
    timeFit:          scoreTimeFit(student.transferTimeline, requirements.estimatedTerms),
    supportFit:       university.supportScore ?? 70
  };

  const weighted = (
    scores.majorAlignment   * 0.200 +
    scores.gpaFit           * 0.150 +
    scores.coursework       * 0.150 +
    scores.costFit          * 0.100 +
    scores.locationFit      * 0.100 +
    scores.careerFit        * 0.150 +
    scores.experienceAccess * 0.075 +
    scores.timeFit          * 0.050 +
    scores.supportFit       * 0.025
  );

  return { total: Math.round(weighted), breakdown: scores };
}

function scoreGpaFit(studentGpa, recommendedGpa, minGpa) {
  if (!studentGpa || !recommendedGpa) return 60;
  if (studentGpa >= recommendedGpa) return 100;
  if (studentGpa >= minGpa) return Math.round(70 + ((studentGpa - minGpa) / (recommendedGpa - minGpa)) * 30);
  if (studentGpa >= minGpa - 0.3) return Math.round(40 + ((studentGpa - (minGpa - 0.3)) / 0.3) * 30);
  return 20;
}

// Score interpretation
export function interpretScore(score) {
  if (score >= 85) return { label: "Strong Fit", color: "green" };
  if (score >= 70) return { label: "Good Fit", color: "blue" };
  if (score >= 55) return { label: "Moderate Fit", color: "yellow" };
  if (score >= 40) return { label: "Weak Fit", color: "orange" };
  return { label: "Poor Fit", color: "red" };
}
```

## 9. Curated Seed Dataset Guidelines

The MVP should ship with manually curated JSON data, not live scraping.

### universities.json — Minimum 25 records

```json
[
  {
    "id": "ucla",
    "name": "UCLA",
    "system": "UC",
    "location": "Los Angeles, CA",
    "costCategory": "high",
    "transferFriendliness": 72,
    "supportScore": 80,
    "experienceAccessScore": 90,
    "majors": ["psychology", "political science", "computer science", "sociology", "economics"],
    "careerTags": ["research", "law", "tech", "public policy", "business"],
    "gpaRangeMin": 3.5,
    "gpaRangeRecommended": 3.8,
    "honorsAvailable": true,
    "researchAvailable": true,
    "internshipAccess": "high",
    "officialTransferUrl": "https://admission.ucla.edu/apply/transfer",
    "notes": "Highly competitive. TAG not available for most majors.",
    "sourceDate": "2025-01"
  }
]
```

Seed dataset must cover:
- 10 UC campuses
- 10 CSU campuses
- 5 private/regional universities (e.g., LMU, USF, Chapman, SCU, USD)

### scholarships.json — Minimum 40 records

Each record must include `eligibilityTags`, `minGpa`, `amount`, `deadline`, `sourceUrl`, and `sourceDate`.

Include: Cal Grant, Dream Act scholarships, Jack Kent Cooke, Phi Theta Kappa, MALDEF, HSF, Flicker of Hope, and major-specific awards.

### opportunities.json — Minimum 40 records

Types: internship, research, apprenticeship, honors program, leadership program, campus org, career prep.

Deliverables:

- [ ] Authenticated user reaches `/dashboard`

- [ ] Deployment URL is stable and accessible
- [ ] All pages pass basic accessibility (keyboard nav, aria labels)

## 13. AI Behavior Requirements

### The AI Must Always

- Explain why each pathway fits or does not fit
- Include a disclaimer that data must be verified
- Name specific next steps (not generic advice)
- Flag risks clearly (GPA gap, missing prereqs, timeline compression)
- Label all GPA ranges as estimates

### The AI Must Never

- Guarantee admission to any university
- Guarantee scholarship awards
- Invent course requirements
- Fabricate application deadlines
- Claim to have accessed live data
- Provide legal, medical, or financial advice as professional guidance

### Uncertainty Handling

When data is incomplete, the AI must include:

> "This recommendation is based on the app's current curated dataset. Please verify this requirement directly with your community college counselor and the university's official transfer admissions page."

### Risk Flags the AI Must Surface

- GPA below the minimum estimate for the target university
- Missing required prerequisites
- Transfer timeline shorter than typical (less than 4 semesters)
- Scholarship deadlines within 60 days
- High-cost university with unresolved financial aid questions
- Weak extracurricular alignment to career goal

## 14. Safety, Ethics, and Data

### Disclaimer — Required on Every AI-Generated Page

> "This tool is not a replacement for an official academic counselor, transfer counselor, admissions officer, or financial aid advisor. Always verify requirements with your community college and your target university."

### Data Handling

- Collect only user-entered data — never connect to official student records
- Hash passwords if added later — Replit Auth eliminates this for MVP
- Allow full data deletion: profile, courses, pathways, guidebooks, account
- No public profile sharing by default
- Show consent message before first AI generation: *"Your profile data will be processed by an AI model to generate pathway recommendations."*

### Bias Reduction

- Never discourage students solely on GPA — always show improvement pathways
- Do not make assumptions based on name, income background, or demographics
- Show support resources alongside every risk alert
- Present all pathway tiers as viable with different tradeoffs

### Seed Data Integrity

Every university, scholarship, and opportunity record must include:
- `sourceUrl` — official page
- `sourceDate` — when data was verified (YYYY-MM)
- `isEstimate: true/false` — flag estimated vs. confirmed values

## 17. Risks and Mitigations

| Risk | Mitigation |
|---|---|
| Claude returns malformed JSON | Add retry logic (max 2), fallback to error state with "Try again" |
| Slow AI generation (10–20s) | Full-screen loading skeleton with step-by-step progress messages |
| Neon connection drops | Add connection pooling; catch DB errors and return 503 |
| Seed data becomes outdated | Source dates on every record; prompt users to verify with official sources |
| Scoring feels generic | Weight career goal and GPA heavily; surface breakdown in UI |
| Students misuse as official counseling | Mandatory disclaimer, consent gate before AI generation |
| Replit cold starts | Use Autoscale Deployments; avoid Always-On reliance |
